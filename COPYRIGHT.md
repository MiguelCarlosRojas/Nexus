## 2. Código Fuente y Arquitectura del Juego

El código fuente desarrollado en Ren'Py Script (`.rpy`) y Python para el motor de la novela visual, incluyendo:
- Sistema dinámico de Logros, Experiencia (XP), Nivel y Ranking persistente (`achievements.rpy`).
- Pantallas interactivas y componentes de interfaz gráfica moderna (`screens.rpy`).
- Minijuego interactivo de Piedra, Papel o Tijera (*Janken*) con visión premonitoria.
- Menús modales, barras de desplazamiento y configuración de audio.

Se distribuye bajo los términos de uso para propósitos educativos, de demostración y evaluación comunitaria en este repositorio de GitHub. Para cualquier uso derivado comercial, se requiere autorización previa.
